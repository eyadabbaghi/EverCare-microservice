## 📌 Overview EverCare is a **microservices-based healthcare platform** designed to provide real-time patient monitoring, medical management, and caregiver assistance. The system integrates multiple modules to ensure: - Patient safety - Medical data management - Real-time monitoring - Communication between services --- ## 🏗️ Architecture The system follows a **distributed microservices architecture**: - Backend: Spring Boot (Microservices) - Frontend: Angular - Authentication: Keycloak - Communication: - REST APIs - WebSocket (real-time) - Feign Client (synchronous) - RabbitMQ (asynchronous) - Database: MySQL / PostgreSQL --- ## 🧩 Microservices ### 👤 User & Security - Authentication with Keycloak - Role-based access (Doctor / Patient / Caregiver) - Secure gateway access --- ### 🩺 Medical Record Service - Manage patient medical history - Store clinical data --- ### 📅 Appointment Service - Schedule and manage appointments - Doctor-patient interaction --- ### 📝 Activity Service - Track patient daily activities - Monitor engagement --- ### 🔔 Notification Service - Real-time notifications - Alerts and reminders --- ### 📰 Blog Service - Medical articles and content - User interaction --- ### 📊 DailyMe Service - Mood tracking - Daily logs - Behavioral insights --- ###  ## 🔐 Security - Implemented using Keycloak - Gateway-level security - Role-based authorization - JWT-based authentication --- ## 🔄 Communication Between Microservices - Synchronous: Feign Client - Asynchronous: RabbitMQ Supports multiple real-world scenarios: - Alert propagation - Notification dispatch - Event-driven communication --- ## 🛠️ Technologies - Java 17 - Spring Boot - Angular - TypeScript - MySQL / PostgreSQL - Keycloak - RabbitMQ - WebSocket - Docker ---
